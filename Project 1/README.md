# Student Record Manager

A command-line student record management system built in C.

## Project Status

🚧 **In Development**

This is Project 1 in my engineering project journey.

## Objective

The goal of this project is to learn and apply fundamental C programming concepts by building a small but functional command-line application.

## Planned Features

* [ ] Add student records
* [ ] View student records
* [ ] Search for a student
* [ ] Modify student records
* [ ] Delete student records

## Building

Compile the program using GCC:

```bash
gcc src/main.c -o student_manager
```

Run it with:

```bash
./student_manager
```

## Learning Approach

This project is being developed incrementally.

Each stage introduces a new programming concept and builds upon the previous stage rather than implementing the complete project at once.
